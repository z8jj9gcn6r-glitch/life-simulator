# Life Simulator — согласованные изменения v0.3 (27.10.2026)

Источник требований: Google Drive / Game Design Document v0.1 + утверждённое дополнение v0.2 от 27.10.2026; при противоречиях дополнение имеет приоритет.

## Реализовано в локальном комплекте
- Отсутствие офлайн-расчёта: при скрытии игра ставится на ×0, при следующем запуске — ×0; elapsed ограничен 2 секундами активной работы.
- Воскрешение в момент смерти: $50,000; без исторических снимков, 8 потребностей 100%, отмена действий, возраст/навыки сохраняются.
- Недостающая сумма финансируется только BLACK FOX CAPITAL: 48% годовых, 120 игровых месяцев, комиссия 5% капитализируется.
- Списания в первую очередь из наличных, затем из банковского баланса.
- Серии пропусков: 1 — уведомление; 2 — штраф 5% исходного кредита и рейтинг −3 п.п.; 3 — запрет нового кредита; 5 — ставка +2 п.п.; успешный платёж сбрасывает серию, общий счётчик не ведётся.
- Новый персонаж создаётся с $300 и без долгов; кредитные долги сохраняются при воскрешении старого персонажа.
- Обновлены game-engine, economy, storage, needs, app, ui. Добавлены автотесты.

## Отличия Google Drive и GitHub (на момент аудита)
- На Drive: 4 исходных документа (GDD, экономика, дизайн-система, PDF-референсы), теперь разложены по тематическим папкам. GitHub содержит код, но не эти документы.
- GitHub: 10 файлов, из них 8 JS/CSS/HTML и README; нет js/app.js и js/ui.js. На Drive нет соответствующего опубликованного исходного кода.
- Исходный GDD v0.1 предписывал ×0.5 в фоне и офлайн-расчёт; более позднее утверждённое дополнение заменило это правилом ×0 и без офлайна. Текущий GitHub game-engine.js всё ещё использует старую модель.
- GDD v0.1 описывал восстановление на полгода назад; новое решение заменяет это платным воскрешением в момент смерти. Текущий GitHub game-engine.js содержит устаревшие snapshots/revive.
- GitHub economy.js не содержит кредиты и просрочки; новый локальный комплект содержит.
- UI Design System на Drive использует преимущественно серые цвета и отдельные правила экрана имени; текущий CSS GitHub более синий. Визуальное соответствие требует отдельной калибровки.
- GDD описывает полный набор экономических и жизненных функций, который ещё не реализован ни в GitHub, ни в текущем прототипе; не считать их завершёнными.

## Ограничения
- GitHub API записи возвращает 403 Resource not accessible by integration; поэтому изменения НЕ опубликованы в GitHub.
- В Google Drive обновлены исходный GDD и таблица экономики; ZIP исходного кода v0.3 загружен в подпапку «04 — Исходный код».
- Автотесты проверяют финансовую логику, но реальный запуск на iPhone/Telegram ещё не выполнен.
- Баланс при доходе $120 за работу и платеже порядка $2161/месяц может быть чрезмерно тяжёлым. Условия утверждены как тестовые.
- Техническое допущение: комиссия 5% капитализируется, а автоматический платёж происходит при наступлении каждого игрового месяца.
