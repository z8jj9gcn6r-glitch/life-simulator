# Life Simulator v0.2 — Telegram Mini App

Статический проект HTML/CSS/JavaScript (ES Modules). Для GitHub Pages положите **содержимое** этой папки в корень публичного репозитория, включите Settings → Pages → Deploy from a branch → main / (root), затем настройте BotFather `/setmenubutton` на опубликованный HTTPS URL.

## Проверка
1. Запускайте через HTTP(S), а не `file://` (ES Modules). Для локального теста: `python3 -m http.server 8000` в папке проекта.
2. Первый запуск: имя → уведомление о рождении → главная. Стартовые средства 300 $.
3. Проверить шесть скоростей, вкладки, работу+курс одновременно, отмену, потребности, переводы и повторное открытие.
4. Закрытие/фон переводит скорость в ×0,5 (если не пауза). При возвращении скорость остаётся ×0,5 или ⏸.
5. При ⏸ и ×0,5 потребности заморожены. При ×1 и выше пассивные показатели уменьшаются по реальному времени.
6. Экспорт сохранения: «Ещё» → «Экспорт сохранения». Локальное хранилище может очищаться Telegram/браузером.

## Ограничения
- Дизайн — HTML/CSS адаптация утверждённого макета, **не пиксельная копия**; часть иконок заменена Unicode-глифами.
- Нет утверждённых цен продления жизни, банковских ставок, порогов автопотребностей — эти функции намеренно отключены.
- Система воскресения использует снимки с шагом около 15 игровых дней и выбирает ближайший снимок **не позже** точки за полгода до смерти; при отсутствии снимка откат недоступен.
- Работа/курс/сон/тренировка — тестовые действия с условными эффектами и выплатой. Штрафы за многозадачность, полная модель навыков и критические события — упрощены.
- Нет сервера и межустройственной синхронизации; пользователь может изменить локальное сохранение. Не храните секреты в исходниках.
- Сохранения v0.1 мигрируют частично; незавершённое действие из старого формата не переносится.
- Из-за ограничений мобильного WebView точный момент закрытия не всегда определяется; используйте проверку после сворачивания/возвращения.

## Модули
`game-engine.js` — игровое время, офлайн-проход, снимки, смерть/откат;
`needs.js` — потребности; `actions.js` — действия; `character.js` — персонаж;
`economy.js` — деньги; `storage.js` — сохранение и миграция; `ui.js` — интерфейс;
`app.js` — запуск и обработчики.
