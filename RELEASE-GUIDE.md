# Выпуск следующих версий

1. Создайте новую папку `releases/vX.Y.Z/` с **полными** копиями `js/` и `css/`. Все ES module imports должны оставаться относительными внутри этой папки.
2. Обновите `version.json` до `{"version":"vX.Y.Z"}`.
3. Опубликуйте новые файлы и манифест одним git push. Не удаляйте старые releases.
4. Стабильный `index.html` не требуется менять при обычных релизах. Он каждый раз запрашивает манифест с уникальным параметром и `cache: no-store`.
5. После первого внедрения один раз обновите URL Mini App в BotFather до нового `?v=0.3.3` для обхода старого закешированного HTML. В дальнейшем адрес не меняйте.

Обновление происходит при **новом запуске или перезагрузке**, не посреди игровой сессии. `localStorage` не очищается. На GitHub Pages заголовки кеширования управляются хостингом; запрос манифеста с уникальным параметром предотвращает повторное использование прежнего URL.

## Брендинг

Название игры: **BLACK FOXIA**. Экосистема: **BFCU — Black Fox Club Universe**. Разработчик: **Black Fox Frame**. При обновлении названия не меняйте ключи `localStorage`, чтобы не потерять сохранения.
